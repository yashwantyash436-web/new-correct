# ⚽ FootballVista AI

FootballVista AI is a Streamlit-based Football Analytics Dashboard built using historical international football match data.

## Features

- 📊 Overview Dashboard
- 🌍 Country Analysis
- ⚽ Goal Scorer Analytics
- 🏆 Tournament Analytics
- 📈 Interactive Charts
- 🎯 Key Insights
- 🌐 Streamlit Deployment

## Dataset

- results.csv
- goalscorers.csv
- shootouts.csv
- former_names.csv

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly

## Run Locally

pip install -r requirements.txt

streamlit run app.py
